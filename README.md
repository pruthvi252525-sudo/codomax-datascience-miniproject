# Telco Customer Churn Analysis & Prediction
**Codomax Data Science Internship — Module 5 Mini Project**

## 📌 Project Overview
This project investigates key customer attrition factors in subscription-based services using exploratory data analysis and supervised machine learning. 

## 🔍 Key Insights
1. **Contractual Vulnerability:** Customers on month-to-month contracts exhibit significantly higher churn rates compared to long-term contract cohorts.
2. **Early Lifecycle Retention Risk:** Customer density drops rapidly during the first 12 months, highlighting the necessity for early onboarding intervention.
3. **Financial Sensitivity:** Customers with higher monthly billing rates without complementary tech support have higher attrition likelihood.

## 🛠️ Tech Stack
- **Python:** Data manipulation, statistical modeling
- **Pandas & NumPy:** Ingestion, cleaning, one-hot encoding
- **Matplotlib & Seaborn:** Distribution analysis, multi-panel visual storytelling
- **Scikit-learn:** Random Forest Classifier, ROC-AUC scoring, feature importance extraction
